# 作業実績(コンテナ・成績書)の取得元(GraphQL 版。読み取り専用)

- `packages/features/work_record/lib/src/graphql/work_record_repositories.dart` に、コンテナ・成績書の読み取り専用の取得元を作り、`pms_app` の `graphql_overrides.dart` に足した。
- 名称は、辞書(`shared_appellation`)ではなくラベル(`trans_label`・`trans_label_value`)。書き込みの関数は、辞書用の補助(`20261114_0002`)とは別に、ラベル用の補助が要る。
- 作業実績(読み込みが作業指示を必須にしている)・在庫の状況(DB のビューの列が画面案の項目と合わない)は、サンプルのまま。取得元にするには、画面案(`tools/open-design`)の定義を DB のビューに合わせる必要がある。
- 検証用 DB: コンテナ 2 件(名称のラベルは `ja` の値が無く空)、成績書 0 件。値の対応は、データが入ってから確認する。
- テスト: `test/work_record_connection_test.dart`(PostGraphile、一般ユーザー)2 件を含め 6 件通過。
