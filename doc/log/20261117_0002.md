## 実施した結果
1.  **権限なしの画面**(`app_core`): `AccessDeniedDestination`・`/access-denied`・`AccessDeniedPage`(`assets/access_denied.svg`。`apps/icon/access-denied.svg` の CSS 変数をライトの色に置き換え、`<style>` を除いたもの。`flutter_svg`)。ボタンは 1 つ(ログイン済み → ダッシュボード、未ログイン → ログイン。積まずに入れ替え)。
1.  **判定と遷移の阻止**(`pms_app`): `services/access/route_access.dart`。`gatedAccessPath`(確認が要るページの許可の単位)・`isAdminOnlyPath`・`routeAllowed`(メニューの絞り込みと同じ `menuAccessProvider`)。URL で直接開く → `rootRouter` の `redirect` が権限なしの画面へ。メニュー・リンク → `AccessGuardNavigator`(Decorator。`createFeatureCommandBus` が包む)が、遷移の前に止めて、いまの画面にとどまる。
1.  **ログイン後の遷移**: ログイン成功を `TopLevelDestination(DashboardDestination)` にし、ログイン済みでログイン・登録・再設定のパスを開くとダッシュボードへ向ける(`root_router.dart`)。
1.  **`loadux_lib`**(`packages/ui/loadux_lib`): `LoadingIndicator`(`.centered`)・`LoadingBar`・`LoadingTheme`(`ThemeExtension`)。`theme_lib` には依存しない。`theme_lib` の 2 つの `ThemeBuilder` が `LoadingTheme(color: 主色)` を入れる。`CircularProgressIndicator`・`LinearProgressIndicator` の直接の使用 17 か所(`pms_app`・`app_shell`・`entity_screens`・`flgtable_lib`・`app_core`・`auth_files`・`shared_master`・`user_profile`)を置き換えた。テスト 3 件。
1.  **英語**: 14 機能に `en.i18n.yaml` を追加し、`dart run slang` で生成(`access_control`・`barcode_entry`・`item`・`organization`・`plan_change`・`production_process`・`purchasing`・`quality`・`quality_common`・`quality_document`・`resource`・`sales`・`system`・`work_record`)。`app_core` に権限なしの画面の文言(ja・en)。
1.  **依存**: `pms_app` から `cupertino_icons`・`import_sorter`・`undo_redo` を削除。
1.  **`pms_app_example` のテスト**を、新しい動きに合わせて直した(戻る操作でログインへ戻れない・ログイン済みでログインのパスはダッシュボード・許可の無いパスは権限なしの画面・メニュー/リンクは遷移しない)。20 件が成功。
