# 品質管理(苦情・監査・監査基準)の取得元(GraphQL 版。読み取り専用)

- `packages/features/quality/lib/src/graphql/quality_repositories.dart` に、苦情・監査・監査基準の読み取り専用の取得元を作り、`pms_app` の `graphql_overrides.dart` に足した。苦情・監査の題名はラベル(`trans_label`)、詳細は文章(`trans_text`)、監査基準は辞書・文章(`shared_*`)で、言語コード `ja` の値。
- 検証用 DB: 苦情 1 件(題名「異常報告」・詳細・日付・報告者の値を確認)、監査・監査基準 0 件(問い合わせが通ること(空)だけを確認)。
- 親の ID を必須にする読み込みの実体(苦情の子、受注リスク・工程リスク、監査チーム・監査員など)・帳票は、サンプルのまま。取得元にするには、親ごとの取得(`findByParent`)に対応させる(画面案の項目を DB に合わせる必要もある)。
- 書き込みは、ラベル・文章用の補助を含む関数を足してから(入れ替えの印はコードと `issue/202611.md`)。
- テスト: `test/quality_connection_test.dart`(PostGraphile、一般ユーザー)2 件を含め 6 件通過。

# 取得元(GraphQL 版)の全体のまとめ
GraphQL 版の取得元がある機能: `access_control`・`sales`・`purchasing`・`production_plan`(書き込みあり)、`system`・`shared_master`・`item`・`organization`・`resource`・`production_process`・`work_record`・`quality_document`・`quality_common`・`quality`(読み取り専用)。読み取り専用の機能の書き込みは、呼称・ラベル・文章の DB 関数(`doc/query/20261114_0002`。ラベル・文章用は未作成)を適用してから入れ替える。
