# 品目(品目区分・品目)の取得元(GraphQL 版。読み取り専用)

- `packages/features/item/lib/src/graphql/item_repositories.dart` に、品目区分・品目(ツリー)の読み取り専用の取得元を作り、`pms_app` の `graphql_overrides.dart` に足した。名称・読み・略称は言語コード `ja` の辞書の値、詳細は文章の先頭の文、品目の親は品目ツリーの親の品目 ID。
- 品目の親ごとの絞り込みはサーバー側に無いため、取得した 1000 件の中から選ぶ(品目が多くなったら、サーバー側の絞り込みを足す)。
- 書き込みは、呼称の DB 関数(`20261114_0002`)の補助を使う品目・品目区分の関数を足してから(入れ替えの印はコードと `issue/202611.md`)。
- テスト: `test/item_connection_test.dart`(PostGraphile、一般ユーザー)2 件通過。
