# メンテナンス情報サーバー(issue 20261106_0002)

`tools/docker/maintenance` に nginx 1つの docker compose を追加した。
- `/health`: 通常 200、`/data/maintenance.flag` があると 503(アプリの `HttpMaintenanceChecker` の仕様に合わせた)。
- `/info/`: 情報ファイルを GET で読み、Basic 認証つき WebDAV の PUT/DELETE で書く(FTP 不使用)。
- 既定ポート 18480(標準を使わない)。ID・パスワード・ポート・置き場は `.env`(見本 `.env.example`)。
- 未検証: この環境に docker が無く、起動と動作は確認していない。
