# 20261024_0001 業務画面の追加生成（open-design用.md を元に）

## 入力
- 添付 `open-design用.md`（画面構造・共通画面・機能別画面の仕様）
- 取り込み済みプロトタイプ（`index.html` / `tablet.html` / `mobile.html`、`app.js` / `data.js` / `styles.css`、`design/theme.md`）

## 方針
既存のデザイン（ティール系トークン、4/8px 間隔、既存アイコン）を継承し、3つのHTMLを増やさずに画面を追加した。
仕様書の5つの構造を、既存部品への対応で揃えた。

| 仕様の構造 | 実装 |
|---|---|
| テーブル構造 | `makeTable`（検索・並べ替え・列の表示/非表示。編集モードで行クリック→編集画面） |
| ツリー構造 | `gTreeCard`（インデント、展開は遅延読み込み風、編集モードでドラッグ&ドロップ、編集画面の「親」で付け替え） |
| リスト構造 | 既存の `rowi`（メニュー）／件数の少ない台帳はテーブルで代用 |
| 編集構造 | `gEntityScreen`（必須・重複検証、更新者/更新日は編集不可、配下の台帳を下に表示） |
| フレーム構造 | PC=サイドバー+メイン、タブレット=アイコンのみのサイドバー、モバイル=ハンバーガー（ドロワー）+下部ナビ |

## 追加・変更したファイル
- `domains.js`（新規）: 業務画面の宣言。実体（項目・サンプル行・親子関係）と画面（タブ構成）とメニューのグループ。
- `app.js`: 汎用エンジン（`generic domain screens`）、AppCore 画面、保存/削除（`gEnt`）、メニュー、モバイルのハンバーガー。
- `styles.css`: ログイン、設定、テーマ切替（`data-theme`）の追加。
- `index.html` / `tablet.html` / `mobile.html`: `domains.js` を読み込む。

## 追加した画面
- AppCore: ブート（`#/boot`）、ログイン（`#/login`、Keycloak の内部ブラウザ風）、ログアウト（5秒後にログインへ）、エラー（`#/error`）、設定（`#/settings`）
- システム: 単位
- 品目: 品目区分、品目（ツリー。HSコード・大きさ・梱包サイズ・品目工程計画・製造元）、大きさ区分、HSコード
- 工程: 工程（ツリー）、工程グループ、工程パターン
- 営業: 配送区分、顧客台帳（担当者）、受注（明細）
- 購買: サプライヤー、非計上発注、発注、検品（受入明細・成績書）
- 生産計画: 資材所要量計画（生産計画→明細）、充当計画、工程計画
- 作業実績: コンテナ（ツリー）、購入受入、成績書、引当実績、作業実績
- 品質管理共通: 修正処置、再発防止、処置再発防止監視、リスク（未然防止→処置）、監査標準項目
- 品質管理文書: 文書レベル、コンテンツ（ツリー＋文書コンテンツ）、レポート
- 品質管理: 異常報告（全て／顧客クレーム／工程／設備、取込）、受注・工程リスク、監査基準、監査チーム、監査計画

入口は `#/menu`（業務メニュー）とサイドバーの各グループ。

## 未対応・前提
- 既存の会社情報・事業所・部署・作業者・承認・資源・保全は変更していない。
- 列キーは `graphql_provider_lib` のモデルを参照していない。サンプルの項目名で代用した（実装時に差し替える）。
- ログインは見た目の再現（初期値のまま進める）。Keycloak には接続しない。
- 仕様書の「共有」注記（例: 配送区分を営業と購買で共有）は同じ実体を両方のメニューから開く形で表現した。
- 使用言語の切替は選択のみで、画面文言は日本語固定。
- 作成後の表示確認（プレビュー・テスト）は行っていない。
