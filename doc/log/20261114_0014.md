# 呼称の DB 関数(案)の作成と、入れ替えの印

## 内容
- `doc/query/20261114_0002_appellation_functions.sql` に、呼称(多言語の辞書)を持つマスタの登録・更新の関数を作った(`unit_save`・`stakeholder_save`、補助 `ap_*`)。言語コード → 値の JSON で渡し、渡した言語の値だけ入れ替える。
- 検証用 DB で、トランザクション内で実行して ROLLBACK した(DB は変わっていない)。結果は `doc/query/README.md`。履歴のトリガーの都合で `ON CONFLICT` を使わない設計にした。
- 入れ替えの印: コードの doc コメント(`【入れ替え: 呼称の DB 関数】`)、`issue/202611.md` の 2-1、DB への適用依頼 `tools/docker/postgresql/issue/20261114_0003.md`。

## 入れ替え方(適用後)
`unit_save`・`stakeholder_save` を `model_providers` に `kind: function` の `~PageCall` で足し、`system`・`shared_master` の取得元の `save` を呼び出しに入れ替えて、`viewOnly` を外す。
