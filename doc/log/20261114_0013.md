# 共有マスタ(利害関係者)の取得元(GraphQL 版。読み取り専用)

- `shared_master_model/gql/stakeholder_page.yaml` に `StakeholderPage`(役割で絞らない読み込み)を足した(既存の `stakeholder.yaml` は項目の部品で、変更していない)。
- `shared_master/lib/src/graphql/shared_master_repositories.dart` に利害関係者の読み取り専用の取得元を作り、`pms_app` の `graphql_overrides.dart` に足した。名称・読み・略称は言語コード `ja` の辞書の値、顧客・外部供給者・運送業者はフラグ。担当者・配送区分はサンプルのまま。
- 書き込みは、呼称の DB 関数(必須ではない。`20261103_0002.md`)を待たず、まず読み取りから進める方針。関数なしの場合、途中失敗で辞書・呼称の孤児が残り、1 件の登録が 11 往復ほどになる。
- 注意: 検証用 DB に運送業者(`is_logistics`)の利害関係者が無いと、出荷予定の運送業者の選択肢は空になる。
- テスト: `test/shared_master_connection_test.dart`(PostGraphile、一般ユーザー)2 件を含め 26 件通過。
