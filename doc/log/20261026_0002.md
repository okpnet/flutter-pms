# 20261026_0002 pms_authenticator の移動

指示: [issue/20261026_0002.md](../issue/20261026_0002.md)

## 実施
- `git mv legacy/pms_authenticator packages/features/pms_authenticator`(履歴を保って移動。未追跡の `build` なども一緒に移った)。
- `pubspec.yaml`: `resolution: workspace`、`publish_to: none`、SDK・依存を bootstrap に合わせた。`pms_logger`(git参照)を `logger_provider` に置き換えた。`pubspec.lock` は削除(ルートの1つに集約)。
- コード: `pms_logger` → `logger_provider`、`ILogger` → `ILoggerProvider`、`critical` → `fatal`、引数名 `exception`/`stackTrace` → `ex`/`trace`。
- `build.yaml` を追加し、build_runner の対象を `lib`・`test` に限定(`example` の生成物を読んで失敗するため)。`auth_controller.g.dart` 等を再生成。
- `flutter pub get`(ルート)で解決できた。

## 結果
- `flutter analyze lib test`: エラー0件。
- テスト: `callback_server_test.dart` の2件が30秒でタイムアウトする(ローカルのHTTPサーバーを立てるテスト。移動前から同じかは未確認)。それ以外は通る。
