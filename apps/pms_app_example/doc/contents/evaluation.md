# pms_app の評価(pms_app_example。2026-11-17)

方法: `pms_app` の実物(ルーター・セッション・認証・メニューの枠・各機能)を、仮想のサーバー(`VirtualServer`)で動かし、ウィジェットテスト(19 件、すべて成功)とコード・依存の調査で確かめた。**Windows を起動した目視・スクリーンショットは行っていない**(見た目は利用者が確認する)。GraphQL には接続していない(サンプルの取得元)。

| # | 評価の項目 | 結果 | 根拠 |
|---|---|---|---|
| 1 | テーマが適用され、変更できるか | 〇 | 追加のテーマ(ocean・forest)を含めて、選択で主色が変わり、ダーク/ライトのモードが反映される(`shell_evaluation_test`) |
| 2 | ログインユーザーの情報を、必要な画面が取得できるか | △ | 身元(担当者 ID・管理者か)は `userIdentitySourceProvider` から取れる。表示用の `userSummary` は、ログインのとき `name = ユーザーID`(例 `sato`)で、役割(`role`)が空。PocketBase の `name`(氏名)・`role` を入れていない。`currentUserHolderProvider` は GraphQL に接続しないと null |
| 3 | ページ遷移に矛盾・間違いは無いか。異常な遷移を止められるか | △ | 未ログインはどのページもログインへ向く(〇)。存在しないパスはエラー画面(〇)。**ログイン後に「戻る」でログイン画面へ戻れる**(ログインを `push` で積むため)。**ログイン済みでもログインのパスが開く** |
| 4 | セッション切れ(仮想)で、適切なページへ移れるか | 〇 | サーバー側で無効にすると、次のページ移動で「セッション切れ」の案内ページ(`/auth/logout?expired=1`)へ。通信できないだけのときは、ログアウトにせず不明として扱う。メンテナンス中は全ページがメンテナンスページになり、終わると戻る |
| 5 | ファイルのアップロード(仮想)は機能するか | 〇 | アップロードで版が増え、履歴に出て、ダウンロードで内容が戻る。不正な ID は通信せずに入力エラー。接続断でも落ちない |
| 6 | テーブル・フォームの各ラベルは slang か | △ | 画面の文字は slang(各機能の `lib/src/i18n`)。直書きの日本語は、`ui`・`core` の 3 か所(`grid_extensions` の「もっと読み込む」、`feature_host` の「まだ画面がありません」、`condition_editor` の「〜」)と、サンプルのデータ(ダッシュボードの件数の見出し、MRP のサンプルのメッセージ)。**英語の言語ファイル(`en`)は、14 機能に無い**(英語の環境では日本語のまま) |
| 7 | 権限に応じてメニューが隠れ、各ページへの遷移を止められるか | × | メニューは許可されたページだけに絞られる(〇)。**URL・コマンドで直接開くと、許可の無いページ(`/e/item`)も、管理者専用のページ(`/auth/admin/signups`)も開く**(ルーターに許可の確認が無い。メニューの表示だけ) |
| 8 | 不要なライブラリが無いか | △ | `pms_app` の依存のうち、コードから使われていないのは `cupertino_icons`・`import_sorter`(開発用)・`undo_redo`。ワークスペースで、ほかのパッケージから参照されないのは `ui_mapper`・`return_model`・`supply_model`(後の機能のためのモデル)・`jwt_verification_test`(テスト専用)。`graphql_flutter`・`connectivity_plus` は削除済み |
| 9 | 接続できないとき、エラーを返すか | 〇 | ログイン・共有ファイルは「サーバーに接続できませんでした」を表示して落ちない(仮想)。GraphQL は `pms_graphql` の `NetworkError`・`SessionExpiredError`・`SessionUnavailableException`(既存の通信テスト)。この評価は GraphQL に接続していない |
| 10 | 読み込み中の円は、ライブラリ化・抽象化されているか | × | `CircularProgressIndicator` を、17 のファイルで直接使っている。覆い(`app_shell` の `BusyOverlay`)は 1 つあるが、通常の読み込み中の表示は部品になっていない。`pms_app` に別の `OverlayIndicator`(Cupertino)と `BootSplash`(Material)がある |
| 11 | サイドメニューの項目に、漏れ・不要は無いか | △ | 項目は 78 件。すべてパスに解決でき、開いてもエラー画面にならない。重複は 1 件(配送区分。営業・購買の両方から開く仕様)。**メニューにも、ユーザーメニューにも入口が無いページ**: 共有ファイル(`/auth/files`)・管理者の画面(`/auth/admin/signups`・`/auth/admin/resets`)。`auth_files` はメニューの項目を持たず、遷移先(`SharedFilesDestination` など)を呼ぶ画面も無い。ほかに `/profile/display`・`/e/stakeholder` もメニューに無い(入口の有無は未確認) |

詳細な指摘と提案は `issue/20261117_0002.md`。
