# 開発用の仮のログインを廃止し、接続先が未設定のときはエラーにする

## 問題
接続先(PocketBase)が空だと `AuthMode.provisional` になり、ログイン画面が「標準のユーザーでログイン」のボタンだけになっていた。
ID・パスワード欄が無いため、裏設定の入口(`BackstageEntryGate`)を通せず、裏設定で接続先を設定できない行き詰まりになった。

## 対応
1. `AuthMode.provisional` を `AuthMode.unconfigured`(接続先が未設定)に変更した。標準のユーザーでログインする動きは廃止。
2. ログイン画面は常に通常の画面(ID・パスワード欄)。裏設定の入口に一致すれば裏設定へ進む。一致しない通常のログインは、
   `AuthServerUnconfiguredException` で「接続先が設定されていません」のエラーにし、通信しない。
3. 文言 `login.provisionalNotice` / `provisionalSubmit` を削除し、`errors.serverUnconfigured`(ja・en)を追加した。`dart run slang` で再生成。
4. `pms_app` 側は、未設定のセッション確認を常にログアウトにし(`UnconfiguredPageSession`)、ルーターの `authRedirect` を常に適用した。

## テスト
- `auth_files`: 48件通過(未設定でも入力欄がある・入口に一致できる・通常ログインはエラーになり通信しない を追加)。
- `pms_app`: 31件通過。
