指示: `issue/20261104_0001.md`。調査のみ(実行は方針の確認後)。

## 現状
- `services/router/root_router.dart` の `rootRouter` が3つを並べる: ① mock_up 由来の型付きルート(`contents/_controller/contents_control_router.dart` の `$appRoutes`)、② 枠の外の機能(`standaloneFeatureModules`: maintenance、ログイン前の auth_files)、③ `ShellRoute` の中の機能(`featureModules`)。
- `go_router_builder` は導入済みで使用中。対象は mock_up 由来の `TypedGoRoute` 5つ(`register_material_transfer`・`register_shipping`・`stock_state`・`lits_shipping`・`login`)と `TypedShellRoute`/`TypedStatefulShellRoute`。機能(`packages/features`)のルートは、アノテーションなしの `GoRoute`。
- `flutter analyze`: 17件、すべて `lib/extensions/nested_map_flattener_example.dart` の `avoid_print`(info)。
- メニューの分類は `AppMainFrame` が各機能の `MenuContributor` の `groupId` でグループ化している。「機能(メニュー分類)をもとにサブメニュー、各ページへ展開」は既に動いている。
