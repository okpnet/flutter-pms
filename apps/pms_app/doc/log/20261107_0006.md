# issue 20261107_0006 の実施(Node.js・実サーバーのある環境)

環境: Node.js 18、PocketBase(192.168.1.103:8090 → 200)・PostGraphile(192.168.1.100:5000 → POST 200)に接続できる。docker は無い。

## 2. 画面の追加(一部実施)
1. `node tools/entity_gen/gen.js` を実行した。
   - 出荷予定台帳(`shipplan`)と出荷指示(`shipline`)が「プロジェクト未割当」になったため、画面案のグループ `ship`(出荷管理)を営業(`sales`)のメニューへ割り当てた(`GROUP_PROJECT.ship`)。
   - 計算項目(`kind "c"`)は、読み取り専用の数値(`FieldKind.number`・`readOnly`・必須でない)として生成する。値は DB・GraphQL の集計で返す(サンプルは空)。出荷待ちの割合(`shipplan.wait`)が該当。
   - 生成の結果、`sales` に `shipplan`(台帳)と `shipline`(子の台帳)が増えた。`sales` のテスト 8件、`pms_app` 37件が通る。
   - 生成のたびに他の機能の `example/lib/main.dart` が古い雛形で上書きされる(`darkThemeOf`・`themeModeOf` が消える)ため、`sales` 以外の生成物は戻した(雛形の更新が必要。issue)。
1. アクセスパス: `tools/entity_gen/access_paths.js` の `EN` に `shipplan` を足し、`doc/contents/access_paths.csv` に `/e/shipplan` を追加した。
