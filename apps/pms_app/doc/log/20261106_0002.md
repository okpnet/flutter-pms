# 20261106_0002 起動からログイン画面まで

指示: [issue/20261106_0002.md](../issue/20261106_0002.md)

## 1. 起動中の読み込み表示
- 原因: 起動の処理(裏設定・ログ・テーマ・設定・ダッシュボードの復元)が同じ isolate で続けて動き、回転が止まって見えた。加えて `runApp` の前の準備中は何も表示されなかった。
- 対応: `main()` の最初に `BootSplash`(読み込み中)を `runApp` し、準備のあとに本体を `runApp`。起動の各段階のあいだで `yieldToFrame()`(次の1フレームを描画)を挟む。仮の待ち時間(3秒)は削除。入口のハッシュ計算(PBKDF2)は元から別の isolate。
- 実機での目視は未実施(ユーザーが行う)。ページ読み込み時(リダイレクトでの確認)の表示は変えていない。

## 2. デバッグ用の裏設定
- `tools/config_user_generator/entry.json` の入口を `assets/backstage.json` の `entry` に反映した(`defaults` はそのまま)。
- `tools/config_generator/backstage_config.enc.json` を `assets/debug/` にコピーし、デバッグビルドだけ、exe と同じフォルダに無いときにこのアセットを読む(`loadEncryptedBackstageConfig`)。暗号化済みだが、ツール側と同じく Git に入れない(`.gitignore`)。アセットはフォルダ指定のため、ファイルが無い環境でもビルドできる。
- 暗号化した設定は、入口のパスワードで復号される。`entry.json` を作ったときのパスワードで暗号化していること。

## 3. ログインの事前評価と失敗時の扱い
`auth_files` 側で実装(`packages/features/auth_files/doc/log/20261106_0002.md`)。メンテナンス → 裏設定 → ログイン → JWT の順で、失敗はそれぞれ、メンテナンスのページ・ログインに留まる・メッセージ・メッセージ(セッション破棄)。
