# 2026/09/02_001 logger_provider 初回実装

## 変更概要
`flutter create --template=package` のスケルトン状態だった `logger_provider` を、CLAUDE.md の設計に基づき実装した。

- `pubspec.yaml` に `logger: ^2.7.0` と `rotation_log: ^0.1.1` を追加（`flutter pub add` により解決）。
- `logger_lib` の `LoggerProvider<T>` / `ILoggerProvider` を実装する [DefaultLoggerProvider](../../../lib/src/default_logger_provider.dart) を追加。
  - `T` には `package:logger` の `Logger` を採用。
  - フィルタは `ProductionFilter` を採用（既定の `DevelopmentFilter` は `assert` 経由で判定するため release ビルドで常に出力が止まる問題があり、ローテーションファイル記録が目的の本パッケージでは不適切と判断）。
  - 出力先は `rotation_log` が提供する `RotationLogOutput`（`logger.LogOutput` 実装）をそのまま利用し、必要に応じて `ConsoleOutput` と `MultiOutput` で束ねる。
- 設定を1つのJSONオブジェクトとして扱う [LoggerProviderConfig](../../../lib/src/logger_provider_config.dart) を追加し、`logger` / `rotation` それぞれの設定を [LoggerConfig](../../../lib/src/logger_object/logger_config.dart) / [RotationConfig](../../../lib/src/rotation_object/rotation_config.dart) にネストして保持する構成にした。
- 生成手段として、設定クラス・Map(JSON)・アセットパスの3種を受け取るファクトリメソッド（`DefaultLoggerProvider.fromConfig` / `.fromMap` / `.fromAsset`）を実装した。
- ディレクトリ構成・命名規約（snake_case、各DIRにアンダースコア始まりの同名バレルファイル、トップレベルは1ファイルのみ）に従った。

## 仕様変更・判断メモ
- CLAUDE.md 内のパス誤記（`flutter_pb_lib` → `flutter_pub_lib`）を修正済み（本実装より前のドキュメント更新セッションで対応）。
- `rotation_log` 0.1.1 は `logger` パッケージの `Level` をそのまま再利用しているため、ログレベルの型は `logger_provider` 内で独自定義せず `package:logger` の `Level` を共通で使用した。
- ログ保存先ディレクトリはテスト・上位アプリ側で差し替えられるよう、各ファクトリに `directoryProvider` を任意パラメータとして用意した。
