# 20261116_0001 スカラーを返す kind: function への対応

指示: `issue/202611.md` の 2-5(ルートの `issue/20261116_0002.md`)。

1.  `kind: function` の `returns:` が、スカラー(`Int` など。PostGraphile はペイロードのフィールドにする。例 `visiter_owner_rebuild` の `integer`)のとき、`columns:` を書かずに、フィールドをそのまま選ぶ(`integer`)ようにした(`lib/src/function_generator.dart`)。オブジェクトを返す関数は、これまでどおり `columns:` が必須。
1.  テストを 1 件足した(`test/view_graphql_generator_test.dart`)。このパッケージのテストは、関数・生成のものが通る。`page_views_consistency_test.dart` の 2 件は、手元の本家スキーマ(`.schema/schema.graphql`)が古いために失敗する(アクセス管理・`ScanVisiterPage` などがスキーマに無い)。`melos run gql:schema` で更新したあとに確認する(`issue/20261116_0002.md`)。
