# 20261103_0001 JWT の担当者クレームの不一致(pb_user_id の列は不要)

`packages/model_providers/issue/20261103_0002.md` の調査(`packages/model_providers/doc/log/20261103_0002.md`)の結果。

## 担当者の紐付け
PocketBase の `users.app_user_id` に `info_staff_id`(UUID)を入れる。`info_staff` に `pb_user_id` の列は足さなくてよい(逆引きが必要になったときだけ検討)。

## 対応が必要な点
DB の関数(`07_visiter_functions.sql` の `visiter_staff`、`08_mrp.sql`)は `jwt.claims.staff_id` を担当者として読む。PocketBase の GraphQL 用 JWT のクレームは `sub`・`pb_user_id`・`app_user_id`・`app_role` で、`staff_id` が無い。
1. PocketBase の `tools/docker/pocketbase/pocketbase/pb_hooks/50_graphql_token.pb.js` に `staff_id`(= `app_user_id`)を足す(推奨。DB の関数を変えない)。
1. または、DB の関数が `jwt.claims.app_user_id` を読むように変える。
