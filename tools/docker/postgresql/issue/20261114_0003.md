## 内容
- `unit_save`・`stakeholder_save`(公開)と、補助 `ap_staff`・`ap_language`・`ap_dictionary_set`・`ap_text_set`・`ap_appellation_set`(`@omit`)。
- 呼称(名称・読み・略称)・詳細の文章を複数の表へ登録する処理を、1回の呼び出し = 1トランザクションにする。途中で失敗しても、辞書・呼称の孤児が残らない。1件の登録が 1 往復になる。

## 影響の範囲
- DB: 関数の追加だけ。既存の表・制約・自動 CRUD の mutation は変わらない。補助の関数は `@omit`(GraphQL に出ない)。
- PostGraphile: `unitSave`・`stakeholderSave` の mutation が増える(`melos run gql:schema` で取り込み)。`jsonb` の引数は JSON の文字列。
- クライアント: 適用までは読み取り専用。適用後に、`system`(単位)・`shared_master`(利害関係者)の取得元の `save` を入れ替える。

## テスト結果への対応(2026-11-15)
- 更新を「渡した項目だけ」にそろえた(渡さなかった項目が消える指摘)。
