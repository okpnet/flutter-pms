## 2. `mrp_purge` を `mrp_run` の中で呼ぶ(判断 F5-3。案 2)
1.  `tests.mrp_run` の、排他ロック(`pg_advisory_xact_lock`)の取得の直後・失効(`UPDATE trans_mrp_run SET status = 3 WHERE status = 0`)の前に、**新規 MRP(`p_mode = 1`)のときだけ** `PERFORM tests.mrp_purge();`(破棄・失効して 30 日を過ぎた実行を削除)を呼ぶ。再 MRP(`p_mode = 2`)では呼ばない。
1.  削除の失敗で MRP を失敗させない: `BEGIN … EXCEPTION WHEN OTHERS THEN RAISE WARNING … END` で囲む。外部キーが遅延(`DEFERRABLE INITIALLY DEFERRED`。コミットで検査)のため、ブロックの中で `SET CONSTRAINTS ALL IMMEDIATE;` → `SET CONSTRAINTS ALL DEFERRED;` として、違反をその場で捕まえる(ブロックの中の削除は、失敗すると取り消される)。
1.  削除のたびの外部キーの検査(参照元の走査)のため、参照元に索引を足した(PERO・06 に反映済み): `trans_plan_change_ix95`(`trans_mrp_suggestion_id`)・`trans_plan_change_ix96`(`reflected_trans_mrp_run_id`)・`trans_mrp_pegging_ix3`(`demand_trans_mrp_suggestion_id`)・`trans_mrp_pegging_ix4`(`supply_trans_mrp_suggestion_id`)・`trans_mrp_suggestion_ix4`(`parent_trans_mrp_suggestion_id`)・`trans_mrp_suggestion_task_ix3`(`outsource_trans_mrp_suggestion_id`)。
1.  **確認してほしいこと**: ① `BEGIN; …適用…; SELECT tests.mrp_run(1); ROLLBACK;` で、`mrp_run` が通ること(`SET CONSTRAINTS` の入った関数が、`mrp_execute` の中で呼ばれても通ること)。② 削除の対象が、実行・提案・提案工程・ペギング・負荷の全部で消えること(ダミーの破棄・失効の実行を 31 日前にして)。③ 削除の行数・時間を測る(索引の追加の前後)。④ 確定(status 1)の実行は削除されず残る(計画変更が参照するため)。確定した実行の古い負荷・ペギングを間引くかは未決。

## 3. `mrp_equipment_load` の削除(判断 F5-2)
`tests.mrp_equipment_load(date, date)`(設備 × 日の確定済みの負荷)は、MRP から呼ばれず、画面・モデルからも使われていなかった。設備の空きの調査は `mrp_run` の内部(`mrp_capacity`・`trans_mrp_load`)で行う。PERO・06 から削除した。**既存の DB には** `DROP FUNCTION tests.mrp_equipment_load(date, date);` を流す(PostGraphile の `mrpEquipmentLoad` が消える。`melos run gql:schema` で取り込む)。クライアントの `mrp_method/mrp_equipment_load.graphql` は削除済み。

## 3-2. `mrp_check_order_import` の削除(判断 F5-1)
`tests.mrp_check_order_import(jsonb)`(取り込み前の行の確認)と、その戻り値の型 `tests.mrp_import_check` は、使われず、取り込みの機能の予定も無いため、PERO・06 から削除した。**既存の DB には** `DROP FUNCTION tests.mrp_check_order_import(jsonb); DROP TYPE tests.mrp_import_check;`(関数が先)。PostGraphile の `mrpCheckOrderImport` が消える。クライアントの `mrp_method/mrp_check_order_import.graphql` は削除済み。`mrp_check_items`(同じ検査を、品目で行う関数。`mrp_run` も使う)は残す。
