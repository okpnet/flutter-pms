# 20261029_0001 購入品・品目仕入先

- 購入品(`purchase`)と品目仕入先(`itemsupplier`)は、画面案(`tools/open-design/domains.js`)から生成する。`entity_screens` に真偽・無効化・下限・必須の条件・外せない条件を足した。
- 購入品は mstr_item.catalog_item(DB のコメント『購入品』。08_mrp.sql では購入品フラグとして参照される)に対応する。画面案の purchase を、生成のときに catalog_item へ置き換える。item_model の ItemPage は catalog_item を持つ。
