# 20261107_0001 購買: ダッシュボードの集計値の元

指示: `apps/pms_app` の issue `20261107_0003`(購買に関連する実装)。

## 調査(実装の前)
- 既存の issue `20261027_0001`(単価・集計の項目)と `20261029_0001`(品目仕入先・単価)は、定義(`unit_price`・`price_adjustment`・`fixed_price`・`material_supply`・`itemsupplier`・`purchase_amount`・`received_amount`)が入っていて、ログもあるため、完了(`D_`)にした。
- `purchasing_model` に `PurchaseAmountPage`・`PurchaseDeliveryCompliancePage` の読み込みが生成済み。ダッシュボード用の集計値の元は未実装だった(model_providers のダッシュボード用ビューの表に載っている)。

## 実施
- `purchasing_api.dart` と `lib/src/dashboard/purchasing_metric_sources.dart`: 2つの集計値の元。
  | 元 | 主値 | 内訳 |
  |---|---|---|
  | 発注金額 | 発注金額の合計(円) | 入荷金額・発注数量・入荷数量 |
  | 発注納期遵守率 | 遵守率(%)= 遵守 ÷(遵守 + 遅延) | 遵守・遅延・期限超過・未完了 |
- `pubspec.yaml` に `dashboard_container`・`data_strategist`・`graphql`・`pms_graphql`・`purchasing_model`(dev: `data_test_harness`)を追加した。
