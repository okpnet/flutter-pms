# 20261029_0001 品目仕入先・明細の単価

- 品目仕入先: `item` の `itemsupplier` を購買のメニュー(サプライヤーの次)に出す(表の中の表)。
- 発注明細(`purdetail`)・非計上明細(`unrecdetail`)・受注明細(`orderdetail`): `cost` を `unit_price` に改名し、`price_adjustment`・`fixed_price` を追加。発注・非計上には `material_supply`・`paid_supply`(材料支給・有償支給)を追加。受注明細には `master_error_count`(マスタ不備件数。読み取り専用)を追加。
- 発注金額・入荷金額(`v_purchase_amount`)は、`unit_price` から計算する(サンプル)。
