# ダッシュボード

pms_app の `issue/20261026_0003.md` の指示。

1. ダッシュボードはユーザーがカスタマイズできる(部品の追加・削除・並び替え・大きさ)。カスタマイズは設定として保存し、起動時に復元する。
2. 保存は `settings_keeper`(アプリが`shared_preferences`を選ぶ)で行う。保存する形のJSONモデルは `app_core` に定義する(`UserSettingsModel` と同じ方式で、画面配置のモデルを持つ)。
3. 画面配置のシリアライズは `packages/ui/ui_mapper`(画面配置のシリアライザ)を使うか確認する。使えない場合は理由を `doc/log` に残す。
4. ダッシュボードに置ける部品は、各機能(ライブラリ)が提供する。機能が部品を提供するための契約(`FeatureModule` の拡張、または別の口)を `feature_shared` に定義する。
5. 部品の元データがDBのviews(`graphql_provider_lib`)に無い場合は、Yamlの追加を `graphql_provider_lib` の `issue` に起こして知らせる。
6. `app_core` が提供するページにする(`AppCorePaths` にパスを追加し、アプリの `/dashboard` を置き換える)。
