#   レビュー
##  ログイン/ログアウト
1.  `flutter-pms\packages\features\auth_files`を使用する(している)が、ログアウト/ログインの画面が機能として同じなものの、別々に画面が存在する、またはないため、調査、別々にするべきか評価、評価結果に応じて画面を集合の実施を実行する。
    1.  画面の集合後は、関連していた機能の調査、修正/変更を実施する
##  202611050001(4. 課題・提案)への対応
1. 画面案の `--focus`・`--seg-1`・文字の大きさ(28/20/16/14/12)は、まだ `ThemeData` に持たせていない(`ColorScheme` に収まらない値)。`ThemeExtension<AppColors>` を `theme_lib` に足し、フォーカスリングやタイポグラフィも合わせるか決める。
=>あわせる

2. ログアウト・ブートなどの他の `app_core` の画面は、まだ画面案の構成(丸いアイコンのカード)に合わせていない(エラー画面だけ)。
=>あわせる

3. `ocean`・`forest` はシードだけで、画面案の配色ではない(他のテーマとして残している)。
=>採択。このまま残し、`ocean`・`forest` に不足している項目を追加し、完成させる

4. pms_app は `lightThemeProvider`・`darkThemeProvider` を使うので、既定の変更がそのまま適用される。ユーザー設定の「テーマの変更」画面は未実装。
=>設定画面にテーマ変更を追加する。`ocean`・`forest`は外部ファイルとし、テーマライブラリを通してインポートできるようにする。テーマ内の設定は別のアプリケーションで行うため、このプロジェクトでは実装しない。

5. フォント(Noto Sans JP)は同梱していない。Windows では Yu Gothic UI などの代替になる。同梱するなら `pubspec.yaml` のアセットに追加する。
=>フォントは規定/標準/システムフォントを使用し、同封しなければならない場合はメイリオとする
