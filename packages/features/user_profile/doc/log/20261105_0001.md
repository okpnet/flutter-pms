# ユーザー情報の表示パターン(small・medium・large)

`issue/201105_0001.md` の実装。実装可能と判断した。表示の部品 `UserContainer` は `packages/ui/app_shell` にあるため、そこを変更した。

## 変更
1.  `app_shell`: `UserContainerSize`(small・medium・large)、`UserField`(name・callName・role・department)、`UserDetailBuilder` を追加。`UserContainer` は `size`・`fields`・`detail` を受ける(`compact` は `size: small` に置換)。`AppUser` に `callName`・`department` を追加。
    1.  small: 小さな顔写真のみ。メニューがあればタップで開く。▼は出さない。
    1.  medium: 顔写真 + 選んだ項目。メニューがあるときだけ▼とメニュー。
    1.  large: 大きな顔写真 + 項目 + 詳細(デリゲート)。メニューは持たない。
    1.  メニュー(`actions`)が空なら、▼もメニューも出さない。
1.  `AppTitleBar`: モバイルは small、それ以外は medium(従来の見た目)。
1.  `user_profile`: 確認用の画面「表示パターン」(`UserDisplayDestination`、`/profile/display`)を追加。`example` の起点に載せた。

## テスト
`app_shell`(+4)、`user_profile`、`example`(+1)、`pms_app` が通過。`dart analyze`(app_shell・user_profile)は指摘なし。
