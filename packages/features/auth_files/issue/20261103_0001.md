# ログイン画面のアプリへの組み込みと、PocketBase のセッション確認

`issue/20261102_0001.md` で作った画面(ログイン・新規登録・パスワードを忘れた・認証コードの入力・新しいパスワード・共有ファイル・管理者の2画面)を、アプリで使えるようにする。

## 確認したこと
- ログイン画面は画面案(`tools/open-design/index.html` の `#/login`、`app.js` の `loginScreen`)に沿って実装済み。見出し「生産管理にサインイン」、必須の印つきの2欄、「パスワードを忘れた」「新規登録」のリンク、案内の帯、処理中の表示。画面案の Keycloak の枠(内部ブラウザ風のアドレス表示)は、PocketBase に合わせて省いてある。ラベルは「ユーザー名」を「ユーザーIDまたはEメール」に変えてある(サーバーが両方で照合するため)。**画面そのものの作り直しは不要**。
- 未実施は次の3点(`doc/log/20261102_0001.md` の「未実施」)。

## 追加・変更すること
1. **`example`(ビジュアルテスト)**: `packages/features/CLAUDE.md` の規則どおり、`example` に Windows 向けの確認アプリを置く。`FeatureHost` で全画面の遷移先を並べ、`test/widget_test.dart` で起動と遷移を確認する。PocketBase に接続せず、`pbapi` のサービスを差し替えて動かす。
1. **アプリへの組み込み(`apps/pms_app`)**:
   - ログイン前の画面は枠(`ShellRoute`)の外、共有ファイルと管理者の画面は枠の中に置く。`AuthFilesModule` が2つに分けて組み込めるようにする(`includeEntry`・`includeFramed`)。
   - `--dart-define=POCKETBASE_URL=…` を指定したとき、最初の画面をログインにし、ログインしていなければ(ログイン前の画面を除いて)ログインへ向ける。指定しないときは、これまでの動き(Keycloak・仮のログイン)のまま。
1. **`IPageSessionMediator` の PocketBase 版**(`apps/pms_app`): ページの切り替えのたびに `SessionService.ensureSession` で確認し、`valid`・`expired`・`signedOut`・`unknown` を返す。通信できないときは、ログアウトにせず `unknown`。

## 規則
1. ログイン前の画面と枠の外の遷移は、画面案の見た目と項目に従う。ラベルは slang(`ja`・`en`)で変える。
1. セッションの確認は、短い間隔内の再確認を省く(ページを移るたびにサーバーへ問い合わせない)。
1. パスワード・トークンをログに残さない。
1. 他の機能が使うのは `auth_files_api.dart` の型と、アプリが `pbConnectionProvider` を差し込むことだけ。
