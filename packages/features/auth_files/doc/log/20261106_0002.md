# 20261106_0002 ログインの事前評価(pms_app の issue 20261106_0002)

## 問題と対応
ログインの送信で、評価の順序と失敗時の扱いが決まっていなかった。次の順にした(`lib/src/pages/login_page.dart`)。

1. ソフトウェアベリファイ(必須入力。既存の `FormRules`)→ 項目ごとのメッセージ
1. メンテナンス中か(`pageSessionMediatorProvider.refresh()` が `maintenance`)→ 送信せず、ルーターを評価し直してメンテナンスのページへ
1. 裏設定の入口 → 裏設定へ。進めなかったときはログインのページに留まる(エラーはログへ)
1. ログイン(サーバーの判定)→ 不一致はメッセージ
1. JWT(GraphQL 用)の取得可否 → 取得できなければセッションを破棄してメッセージ(`errors.jwtUnavailable`、`JwtUnavailableException`)

## テスト
- `test/auth_files_test.dart`: JWT を取得できないとき(メッセージ・ダッシュボードへ進まない・セッション破棄)、メンテナンス中は送信しない、を追加。47件通過。
- サーバーに接続できない環境のため、実サーバーでの確認は未実施(別環境で行う)。

## issue への対応
過去の issue 4件(`20261102_0001`〜`20261106_0001`)は、対応するログがあり、このアプリのテストを通過したため `D_` を付けた。
