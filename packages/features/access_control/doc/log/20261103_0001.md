# 20261103_0001 access_control(アクセス管理)の追加

1. 画面の定義を `tools/open-design/domains.js` に追加(アクセスパス・部署のアクセスパス・担当者のアクセスパス許可・担当者の実効アクセスパス。メニュー「アクセス管理」)。
2. `tools/entity_gen/gen.js` にプロジェクト `access_control`、`tools/entity_gen/page_codes.js` に機能コード `X` を追加し、定義・サンプル・表示名・モジュールを生成。

## 検証

## 提案・未解決
1. 取得元はサンプル(メモリ上)。`access_control_model` を使う GraphQL 版のリポジトリ(`IDataRepository` 経由)は未実装。
2. 画面案(Html)は `tools/open-design` の定義から出るため、`doc/contents` の個別の Html は未作成。
3. 部署・担当者の選択肢は `@departments`・`@employees`(open-design のサンプル)。GraphQL 版では `organization_model` に差し替える。
4. 実効アクセス権の権限の確認(ページ遷移の可否への反映)は、認証(PocketBase)の導入と合わせて `IPageSessionMediator` の実装で行う想定。
5. 表示名は DB のコメントが無いため仮(`ja.i18n.yaml`)。
6. `node tools/entity_gen/gen.js` は他の機能の生成物(`organization`・`resource` など)も書き換える。今回の実行で出た差分は、本件と無関係。
