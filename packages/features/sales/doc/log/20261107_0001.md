# 20261107_0001 営業: ダッシュボードの集計値の元(issue 20261027_0001 の適用)

指示: `apps/pms_app` の issue `20261107_0003`(営業に関連する実装)。対応する `issue/C_20261027_0001.md`。

## 調査(実装の前)
- `sales_model` に `SalesRecordPage`・`ShippingOrderStatusPage`・`ShippingDeliveryCompliancePage` の読み込みが生成済み。BigFloat は `String?`、件数は `BigInt?` で届く。
- `organization` の `StaffCountMetricSource`(`GraphqlDataRepository` + `RecordingDataRepository` でテスト)が、同じ作りの前例。
- `sales` は `dashboard_container`・`sales_model`・`pms_graphql` に未依存だった。
- `dashboard_container` に、集計値の元(`IMetricSource`)を表示する部品が無い(件数の元 `ICountSource` だけ表示)。
- 出荷オーダー(`trans_shipping_order*`)は `sales_model` にあるが、`sales` の実体の定義(open-design 由来で `order`・`orderdetail` の2つだけ)には無い。

## 実施
- `sales_api.dart`(契約の入口)と `lib/src/dashboard/sales_metric_sources.dart`: 3つの集計値の元を実装した。生成モデルの型は出さず、この機能の行の型(`SalesRecordRow` など)に変換して返す。全ページを `totalCount` まで読む。
  | 元 | 主値 | 内訳 |
  |---|---|---|
  | 売り上げ実績 | 出荷済み金額の合計(円) | 受注金額・受注数量・出荷数量 |
  | 出荷予定受注実績状況 | 出荷残の数量の合計 | 予定数量・出荷済み数量・予定金額・出荷済み金額 |
  | 出荷納期遵守率 | 遵守率(%)= 遵守 ÷(遵守 + 遅延) | 遵守・遅延・期限超過・未完了 |
- `pubspec.yaml` に `dashboard_container`・`graphql`・`pms_graphql`・`sales_model`(dev: `data_test_harness`)を追加した。
- 主値・率の定義は、issue の「要確認」に対する暫定の決定(金額か数量かは元ごとに上表のとおり。率は完了した分を母数にし、期限超過・未完了は母数に含めない)。期間・顧客・品目の絞り込みは未対応。
