# 20261107_0001 ダッシュボードの配置をユーザーごとに保存

指示: [issue/20261107_0001.md](../../issue/20261107_0001.md)(指示したプロジェクト: `apps/pms_app`)

## 実施
- `DashboardContainerOriginator` に `owner`(ログインしたユーザーのID)を追加し、保存先の識別子を `keyFor(owner)` にした。
  - 識別子は英小文字・数字・`_`・`-`・`.` だけの規則があるため、ID は小文字の英数字以外を `_` に置き換え、元のIDの検査値(FNV-1a 32bit、16進)を付ける。大文字・日本語でも、異なるIDは異なる識別子になる。
  - `owner` が無いときは従来の `dashboard_containers`(互換)。
- `DashboardContainersNotifier` が `userSummaryProvider` のユーザー名を持ち主にする。

## テスト
`test/dashboard_owner_test.dart` を追加(識別子の一意性・保存先の規則・メメントの識別子)。13件通過。

## 注意
- 従来の共通の配置(`dashboard_containers`)は、ユーザーごとの配置に引き継がない。ユーザーは初回に初期の配置になる。
