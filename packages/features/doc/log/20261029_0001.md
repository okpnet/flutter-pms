## 4. 未対応・要確認
1. **MRP の GraphQL 実装**: `production_plan_model` の `mrpExecute`(mutation)と `trans_mrp_suggestion` の読み込みを呼ぶ `IMrpGateway` の実装と、通信テスト。生成モデルが必要で、`trans_mrp_*` の `permission denied`(DB の権限。`09_grant_test.sql`)が解消されるまで通信テストができない。既定の窓口は実体なし(失敗にする)なので、本番アプリでは実行すると警告になる。
2. **実行者**: `mrpStaffIdProvider`(`p_staff_id`)は、ログインの導入後に、ログインした担当者の id を差し込む。
3. **表の中の表の親の表**: 親の一覧は検索・並べ替えを持つカード(行ごとに開閉)で、親の表そのものは `flgtable_lib` の表ではない(`flgtable_lib` に、行に子のウィジェットを入れる機能が無いため)。子の表は `flgtable_lib`。`flgtable_lib` に機能を足す場合は別のIssue。
4. **画面案の新しい項目の表示名**: `mstr_item_supplier`・MRP の列名は、画面案の名称を使った(DB のコメントで裏付けられていない分は `tools/entity_gen/out/labels_inferred.md`)。
5. **サプライヤーの選択**: 品目仕入先のサプライヤーは、利害関係者(外部供給者)の選択肢(リスト)から選ぶ。サプライヤー台帳の画面で選ぶ方式(`picker`)は、台帳の別名の画面が無いため未使用。
