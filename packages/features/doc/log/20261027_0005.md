# 20261027_0005 DB変更にともなう view のレビュー

指示: `issue/20261027_0005.md`(`packages/model_providers/issue/20261027_0002.md` のDB変更にあわせて view をレビューする)。

## DB変更と、画面(view)への影響
| DB変更 | 影響する画面 | 結果 |
|---|---|---|
| `trans_purchase_detail.cost` 追加(単価、NOT NULL) | 購買の発注明細(`purdetail`) | **対応**。単価(必須)を追加。生成元は `tools/entity_gen/gen.js` の `FIELD_ADDITIONS` |
| `v_purchase_amount` に `purchase_amount`・`received_amount` | 購買(発注金額・入荷金額) | **未対応(要確認)**。集計の読み取り専用の項目の種類が `entity_screens` に無い。`purchasing/issue` に起票 |
| `info_address.iso3166_2` → `country_code_2` | 会社・事業所の住所(`organization`) | **対応**。国コード(`country_code_2`)を追加し、住所のキーを DB の列(`zip_code`・`phone`・`fax_number`)に合わせた |

## 実施
- 生成元(`tools/entity_gen/handwritten.js`・`gen.js`)を直して `node tools/entity_gen/gen.js` で再生成した。再生成で、全プロジェクトの生成物の冒頭コメント(`model_providers の各モデルパッケージ`)と slang の生成日時が更新された(内容の変更なし)。
- 既存のコミットは、`organization`・`resource` の生成物が整形済み、それ以外が整形なしのため、同じ状態に合わせて差分を小さくした。
- 該当プロジェクトの `issue`・`doc/log`: `organization`・`purchasing` に 20261027_0001 を追加した。

## 確認
- `organization` 6件、`purchasing` 4件、`resource` 4件、`sales` 4件の `flutter test` が成功(他のプロジェクトは生成物の冒頭コメントの更新のみ)。
