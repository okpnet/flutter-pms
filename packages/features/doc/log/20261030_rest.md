## A. 実装の未対応
1. **実体の画面の GraphQL 版**: 取得元はすべてメモリ上のサンプル(`InMemoryEntityRepository`)。`IEntityRepository` を GraphQL で実装して差し替える。サーバー側のフィルタ・ソート・ページング(`FilterCondition`/`SortCondition` → `Expression` の変換の置き場所が未決)、クライアント(エンドポイント・認証・言語ID)の Provider も未定義。顧客台帳(`sales`)は取得全件(上限 `customerFetchLimit`=1000)で、件数が増えたらサーバー側へ切り替える。(`doc/log/20261025_0005/0006/0007.md`、`sales/doc/log/20261025_0002_customer.md`)
2. **削除の参照チェックの GraphQL 版**: DB の外部キー違反を `ShippingKindInUseException` などの使用中の例外に、一意制約違反を `EntityFieldError.duplicate` に変換する。(`doc/log/20261025_0007.md`)
3. **ダッシュボードの件数**: 件数の元は暫定のモック(`MockCountSource`)。`RepositoryCountSource` への置き換えが必要。集計値(`IMetricSource`・`MetricValue`)は、サーバー側集計(`query_builder`)を使う方針で保留中(ワークスペースの `issue/20261027_0003.md`)。保留中は `dashboard_container` のコードを変えない。(`dashboard_container/doc/log/20261027_0001.md`)
   - 着手時に決める要件: 各ビューで表示する値、絞り込みの軸、期間の基準と既定の期間、サーバー側集計か取得後か、内訳表示の要否。
4. **MRP**: 提案の画面を `symbol` に対応させるか(現在は品目コード・品目名のみ)。品目の無い提案は、品目コードの欄に設備のコードを出している。種別の表示名(ja/en)は推論で、DB のコメントに説明が無い。(`model_providers/doc/log/20261030_0001/0002/0003.md`。要再確認: 同ログの「未対応・要確認」の他の項)
5. **MRP の実行者**: `mrpStaffIdProvider` は、ログインの導入後に、ログインした担当者の id を差し込む。(`doc/log/20261029_0001.md`)
6. **認証(Keycloak)**: `pms_authenticator` の初期化・ログインがアプリに接続されていない。ログインは仮のボタンで標準のユーザーへ戻すだけ。ログイン画面とログアウト後の遷移も認証の導入後。`pms_authenticator` の `callback_server` テスト2件が以前から失敗している。(`doc/log/20261025_0008/0009.md`、`pms_authenticator/doc/log/20261026_0001.md`)
7. **画面案に無いテーブル・ビューの画面**: `mstr_equipment_available`/`mstr_outsource_available`(`delivery_interval`)、`mstr_item_task_cost`(工程場所の選択肢をIDで引く)、`mstr_work_calendar`、`v_item_on_hand`、`v_mrp_*`。必要なら画面案を追加する。モデルが無いものは `model_providers` の別の指示も要る。(`doc/log/20261029_0001.md`、`model_providers/doc/log/20261029_0001.md`)
8. **顧客の担当者の子の台帳**: `custcontact`(顧客は専用の画面のため)。サプライヤーの担当者(`suppcontact`)は生成済み。(`doc/log/20261025_0007.md`。要再確認: 利害関係者の共有化後の状態)
9. **サプライヤーの選択**: 品目仕入先のサプライヤーは、利害関係者(外部供給者)のリストから選ぶ。台帳の画面で選ぶ方式(`picker`)は、台帳の別名の画面が無いため未使用。(`doc/log/20261029_0001.md`)
10. **逆引き表示**: 力量・資格の「保持者」の逆引き表示は `reverseLists` で持たせたが、他の逆引きが要るかは画面案次第。(`doc/log/20261025_0007.md`。要再確認)
11. **symbol によるショートカット**(`CLAUDE.md` の Issue)。未確定: 区切りと桁数の形式、機能コード・画面コードの採番、同じ `symbol` が複数の画面にある場合。実装はしない方針。
