## 1. モックの認証の整理(`apps/pms_app`)
削除したもの:
- モックの認証サービス(`services/authorization`: `mockAutorizeService` とその生成物)と状態(`contents/_models/authorization`: `MockAuthState`・`AuthStateType`)。
- `AuthenticatorPageSession`(`pms_authenticator` の `AuthController` を使うセッション確認)と、`pubspec.yaml` の `pms_authenticator` への依存。
- `mock_core_service` の、モックの認証の変化で動くリスナーとページ遷移(`AutoTypeEx`・`DataTimeExtenssion`)。
- `grid_tree.dart` の、使われない `mockAutorizeServiceProvider` の読み取り。
- `lib/i18n` のログイン用の文字列(`login:`。ja・en)。

置き換え: PocketBase に接続しない開発用のセッション確認は `ProvisionalPageSession`(通信せず、ログインユーザーがいれば有効・いなければログアウト)。`pms_authenticator` のパッケージ自体は残している(着手しない方針)。他のパッケージからの依存は無かった。

注意: `mock_core_service` の標準時間の確認(時計の不正操作・標準時間の取得失敗でエラー画面へ)は、モックの認証の変化にだけ結び付いていたため、リスナーと一緒に無くなった(これまでも、モックの認証が変化しない限り動かなかった)。標準時間の確認を起動時に行う場合は、オフラインでも起動できるかを含めて、別の Issue で決める。
