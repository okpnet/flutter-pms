# 20261105_0001 example のテーマ適用(theme_lib と画面案のデザイン)

指示: `issue/20261105_0001.md`。

## 1. 調査: theme_lib は画面案のデザインを適用しているか
**適用されていなかった。** 画面案の正本は `tools/open-design` の `design/theme.md`・`flutter/app_theme.dart`・`styles.css`(トークン)。`theme_lib` の既定(組み込みの先頭 `default`)との差は次のとおり。

| 項目 | 画面案 | theme_lib(変更前) |
|---|---|---|
| 主色(accent) | `#0B6B6F`(ダークは `#5CC3C6`) | シード `#3F51B5`(インディゴ)から自動生成 |
| 画面の地 | `#F2F5F6` / `#0E171D`(カードの白・ダークの面と別の色) | 指定なし(Material 3 の面の色と同じ) |
| エラー | danger `#B3261E`、danger-soft `#FBE3E1`(ダーク `#FF8A80` / `#4A1F1D`) | シードから自動生成(色相が違う) |
| 補助テキスト・罫線 | muted `#4F5E69`、line `#D3DCE1` | 指定なし |
| ダークの配色 | ライトとは独立に調整した値 | ライトのシードから自動生成 |
| 角丸 | ボタン・入力 8、カード・ダイアログ・シート 12 | すべて 3 |
| タップ領域 | 44x44 | ボタン 128x46、アイコンボタン 32 |
| 面の区切り | 影なし・罫線(カード、タイトルバーの下) | Material の既定(影あり) |
| フォント | Noto Sans JP → Hiragino Sans → Yu Gothic UI → Meiryo | 指定なし |
| エラー画面(`#/error`) | 中央のカードに、丸いアイコン(danger-soft の地に danger)・見出し・説明・注記・ボタン | `app_core` のエラー画面は、色なしのアイコンと文字だけ |

補足: MRP の画面(`production_plan`)は、`Card`・`colorScheme.errorContainer`・`colorScheme.error` など `Theme` の色だけを使っている。画面案のように見えたのは、画面側の作りが `Theme` に従っているためで、`theme_lib` の既定が画面案になれば、そのまま同じ配色・角丸になる。

## 2. 実装
### theme_lib(`packages/ui/theme_lib`)
- 既定のテーマ(`openDesignTheme`、`id: default`)を、画面案のトークンと同じ値にした。ライト・ダークは独立の配色。色の対応表は `CLAUDE.md` の「既定のテーマ(画面案のデザイン)」。`ocean`・`forest` は変更なし。
- 色の個別上書き(JSON の `light.colors`・`dark.colors`)に使える名前を追加: `background`(画面の地)・`primaryContainer`・`onPrimaryContainer`・`errorContainer`・`onErrorContainer`・`surfaceContainerHighest`・`onSurfaceVariant`・`outlineVariant`。
- `ThemeMetrics.cardRadius`(任意。省略すると `radius`)を追加。
- `ThemeBuilder`: 画面の地(`scaffoldBackgroundColor`)、カード(影なし+罫線)、ダイアログ・シートの角丸、タイトルバー(下に罫線)、区切り線、チップ、ナビゲーションの選択色、アウトラインボタン、日本語優先のフォント代替(`ThemeBuilder.fontFamilyFallback`)を追加。すべてのテーマに共通。
- 枠線(`outline`)は、画面案の line(`#D3DCE1`)より濃い `#7C8B96`(ダーク `#5B7384`)にした。入力欄・ボタンの枠を背景に対して 3:1 以上にするため(罫線の line は `outlineVariant` に持つ)。
- `usage.md` の JSON 項目表を更新。

### app_core(`packages/features/app_core`)
- エラー画面(`ErrorPage`)を、画面案の `#/error` の構成にした: 中央のカード、丸いアイコン(`errorContainer` の地に `onErrorContainer`)、見出し、エラーの内容、ボタン。色は `Theme` から取る。

### feature_shared / example
- `FeatureHost` に `darkThemeOf`・`themeModeOf`(任意)を追加。
- `packages/features` の example 21 件のうち、テーマを渡す 21 件すべてを、`theme_lib` の既定のテーマ(`lightThemeProvider`・`darkThemeProvider`・`themeModeProvider`)に揃えた(ライトのテーマは既に `lightThemeProvider` だったので、既定の中身が変わったことで画面案のデザインになる。ダークと OS の設定への追従を追加)。`pms_authenticator` の example は `lib/main.dart` が無く対象外。
- 仕様は `packages/features/CLAUDE.md`(ビジュアルテスト 4)、`theme_lib/CLAUDE.md`、`app_core/CLAUDE.md` に追加した。

## 4. 課題・提案
1. 画面案の `--focus`・`--seg-1`・文字の大きさ(28/20/16/14/12)は、まだ `ThemeData` に持たせていない(`ColorScheme` に収まらない値)。`ThemeExtension<AppColors>` を `theme_lib` に足し、フォーカスリングやタイポグラフィも合わせるか決める。
2. ログアウト・ブートなどの他の `app_core` の画面は、まだ画面案の構成(丸いアイコンのカード)に合わせていない(エラー画面だけ)。
3. `ocean`・`forest` はシードだけで、画面案の配色ではない(他のテーマとして残している)。
4. pms_app は `lightThemeProvider`・`darkThemeProvider` を使うので、既定の変更がそのまま適用される。ユーザー設定の「テーマの変更」画面は未実装。
5. フォント(Noto Sans JP)は同梱していない。Windows では Yu Gothic UI などの代替になる。同梱するなら `pubspec.yaml` のアセットに追加する。
