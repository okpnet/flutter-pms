## 判断した点・注意
1. 項目名は DB のコメントに裏付けられないものがある(一覧: `tools/entity_gen/out/labels_inferred.md`)。画面案の名称を日本語として推論した仮の名称。
2. 読み取り専用の台帳のサンプルは架空の値。実データは GraphQL 版の取得元に差し替えるときに入る。
3. デリバリー間隔は DB では interval。画面では時間(数値)にし、変換は GraphQL 版の取得元で行う。
4. 稼働時間・開始時刻は文字(HH:MM)。時刻の入力部品は無いため。
5. 要判断の提案などの MRP の結果は、画面案の実体(読み取り専用)であり、資材所要計算の画面(`MrpPage`)の結果の表とは別に持つ。
6. `doc/page_code_list.yml` を再生成した(新しい画面のコードを追加。既存のコードは変えていない)。
