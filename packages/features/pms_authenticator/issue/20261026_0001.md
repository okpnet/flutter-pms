# 20261026_0001

ページ用の拡張(`page_mediator_extension`)とアプリのセッション確認の組み込み(`packages/features/issue/20261026_0004.md` の項目1)で見つかった課題。

1. `init` の失敗のログで、例外を `ex as Exception` とキャストしている。`Error`(`StateError` など `Exception` でないもの)が投げられるとキャストで落ち、初期化の失敗を記録できない。
2. 未初期化(ログインしていない)かどうかを、呼び出し側が例外なしで知る方法が無い。`checkAndApplyExpiration` は未初期化だと汎用の `Exception` を投げる。
