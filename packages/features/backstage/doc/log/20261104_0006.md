# 20261104_0006 アプリケーションの裏設定の実装

指示: `packages/features/issue/20261104_0006.md`。

## 実装の最初に決めたこと(Issue の指示)
1. プロジェクト: 専用の `backstage`(`auth_files` には置かない)。他の機能が読む値の持ち主であり、認証・共有ファイルと責務が違うため。
2. 入口: 「特定のユーザーIDとパスワード」(案1)。ログインページで一致したときだけ、通常のログインをせず裏設定へ進む。
3. ハッシュ: PBKDF2-HMAC-SHA256(反復 100,000 回、ソルト 16 バイト、32 バイト)。`crypto` の `Hmac` だけを使う(`pms_authenticator` が既に使っているパッケージ。新しい外部ライブラリは足していない)。

## 実施
- `feature_shared`: `BackstageValues`・`backstageValuesProvider`(値を読む窓口)、`IBackstageEntryGate`・`backstageEntryGateProvider`(入口の判定。既定は常に一致しない)。`sidebarIconOnlyProvider` の初期値が裏設定の既定を読む(ユーザーの設定が優先)。
- `backstage`(新規): モデル・検証(URL は https、http はローカルのネットワークだけ)・優先順位(`BackstageResolver`)・保管庫(`SecureBackstageStore`)・入口(`EntryHash`・`BackstageEntryGate`)・起動時の材料(`loadBackstageBoot`)・ページ(枠の外、戻る操作・リンクなし、出られるのは「終了」だけ)・`backstageOverrides`・`bin/make_entry_hash.dart`・`example`。
- `auth_files`: ログインページが入口の判定を呼ぶ(`backstage_api.dart` の遷移先だけに依存)。一致しなければ通常のログインのまま(失敗の表示も同じ)。
- `user_profile`: `isChangeUserImageProvider` を、起動時の値 > 裏設定の値 > 標準の `false` に(`bool.hasEnvironment` で起動時の指定の有無を見る)。
- `pms_app`: 起動時に材料を読み(`loadBackstageForStartup`)、接続先(PocketBase・GraphQL)・メンテナンスの確認先・ログのレベルに解決した値を使う。`BackstageModule` を枠の外のモジュールに追加し、`authRedirect` の `openPaths` に `/backstage` を追加。`assets/backstage.json`(既定値。入口は未設定)を追加。
- ページ一覧・画面コード: `access_paths.js`(`/backstage`、公開)、`page_codes.js`(機能 `Z`、画面 `ZB`)を更新して再生成した(追加のみ)。

## テスト(2026-11-04)
- `backstage`: 35 件(PBKDF2 の既知の値、入口の判定、URL の検証、優先順位、保存、ページ)。`example` 2 件。
- `auth_files`: 34 件(裏設定の入口 2 件を追加)。`user_profile`: 20 件(優先順位の 2 件を追加。`--dart-define=IS_CHANGE_USER_IMAGE=true|false` を付けても通る)。
- `pms_app`、`feature_shared`、`app_core` ほかの結果は、コミットのときのログ(`doc/log/20261104_0006_add_1.md`)に記録。

## 注意・課題
1. 入口のハッシュ(`entry`)は、リポジトリのアセットには入れていない(入口なし)。`dart run backstage:make_entry_hash` で作って、`apps/pms_app/assets/backstage.json` に貼る。
2. 接続先・ログのレベルは起動時に使うため、ページで保存した値は再起動で反映される(`isChangeUserImage` はすぐ)。
3. 従来の仮のログイン(PocketBase を使わないとき)には入口を付けていない。
4. 裏設定のアクセス権: `/backstage` は公開ページ(アクセス権の対象外)。入口を通っていないと開けない(`backstageUnlockProvider`)。
