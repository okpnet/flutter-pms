## 2. 空のfilter
- サーバーで確認: `filter: {and: [{remove...}, {}]}`は`Empty objects are forbidden in filter argument input.`で拒否される。
- `$filter`を持つread 34本は全て同じ形のため、全て拒否される。よって指示どおり、GraphQLはこのまま(unit/licenseのみの修正はしない)。
- 呼び出し側は空のfilterを渡さない(`FlatFilterConverter`の結果が空のときは、`$filter`の既定値`{}`も拒否されるため要検討)。

=>filterがNullでも対応できるように、views側またはshema側の変更後、再生成しテストする。テスト通過したらコミットする。
