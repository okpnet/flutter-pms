# 20261021_0002 プロパティ一覧CSVの列の変更

指示: `issue/20261021_002.md`(20261021_0001の再指示)

## 変更
- `doc/contens/property_list.csv`のヘッダーを`category, db_table_name, db_column, class_name, proerty_name, key_name, type, label, note`に変更した(綴り`proerty_name`は指示どおり)。
- 列`db_table_name`・`db_column`を追加した。
  - view.yamlは`loadViewDirectory`で読み、画面フォルダ名から`~Page`(read)・`~PageEdit`(edit・rfe)のトップノードを探す。生成物のエイリアスとyamlの列(`as`/`name`)を突き合わせて、`from`(テーブル)・列名・`using`(関連のFK列)を得る。
  - yamlに無い箇所(共通定義が生成する呼称の辞書など)は、スキーマの型名(`InfoOffice`→`info_office`)・フィールド名(`zipCode`→`zip_code`、関連は`…By<列>`の列)から求める。
- 19,949行(変更なし)。`db_table_name`が空の行は156行(Query・Mutation・Payloadのクラス)。
- `tool/gen_property_list.dart`と`CLAUDE.md`(規則/仕様 2.)を更新した。

## 既知の事項
- 20261021_0001の事項(全量スキーマに無い子のレコード数フィールド101件は`label`が空)は同じ。
- `iso3166_3`のように数字の前の`_`は、スキーマ由来の推定では復元できない。yamlに列があれば正しく出る(OfficePageで確認)。
