# 20261025_0001 mstr_shipping_kindのviews確認

指示: `issue/20261025_001.md`(`mstr_shipping_kind`に対応するviewsがなければ`shared_master`カテゴリとして追加。あればログへ対応するYamlを記録)

## 結果
対応するviewsが**ある**ため、`shared_master`カテゴリの追加はしない。対応するYamlを以下に記録する。

- 定義: `source/views/sales/shipping_kind.yaml`(共通定義 `ShippingKindReadFields`(read)・`ShippingKindEditFields`(edit))
- 参照: `source/page.md` 200〜201行・214〜215行(配送区分項目・配送区分情報)、`source/views/sales/stakeholder.yaml`(`shippingKinds`が`ShippingKindReadFields`を取り込む)
- `~Page`・`~PageEdit`の単独ページは無い(共通定義のみ)。このため`lib/graphql`に`shipping_kind`の画面フォルダは無く、`doc/contens/property_list.csv`の単独カテゴリにも現れない(`customer_page`・`supplier_page`の子として含まれる)。

## 対応するYaml(source/views/sales/shipping_kind.yaml)
```yaml
# yaml-language-server: $schema=../../schema.json

##### ステークホルダー

# 配送区分の読み込み
ShippingKindReadFields: &ShippingKindReadFields
  kind: read
  from: mstr_shipping_kind
  filter: true
  requiredWhere:
    - languageCode
  defaultWhere:
    - column: remove
      operator: =
      value: false
  columns:
  - mstr_shipping_kind_id
  - code
  - name: labels
    as: labels
    arrayType: toFirstOne
    using: names
    pick: 
      - name
      - pronunciation
      - nickname
    <<: *AppellationLabelsReadFields
  - symbol
  - remarks
  - update_at
  - name: update_user
    as: update_user
    using: [update_user_history_id,update_user_id]
    arrayType: toFirstOne
    <<: *UpdateStaffReadFields

# 配送区分の書き込み
ShippingKindEditFields: &ShippingKindEditFields
  kind: edit
  from: mstr_shipping_kind
  requiredWhere: 
    - mstr_shipping_kind_id
  defaultWhere:
    - column: remove
      operator: =
      value: false
  columns:
    - mstr_shipping_kind_id
    - code
    - name: labels
      as: labels
      arrayType: toFirstOne
      using: names
      pick: 
        - name
        - pronunciation
        - nickname
      <<: *AppellationLabelsReadFields
    - remarks
    - update_user_id
    - update_user_history_id
    - remove
```
