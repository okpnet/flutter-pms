# Logger
1.  ロガーは`①アプリケーション->logger_providerのインスタンスをRiverpodに登録 ->②ILoggerProviderとして受け取る`という流れになることをCLAUDE.mdに追加。①がアプリケーション側で、ライブラリは②を受け取り形になる。
1.  つまり、RiverpodからILoggerProviderを取得すれば解決するため、取得方法、間違いがあれば代替案を提案する。
