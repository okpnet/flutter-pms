# 20261031_0001 選択の結果の共通化(selection_result)

指示: `packages/features/issue/20261031_0001.md` の「無い場合に新しいプロジェクトを作る」。

## 評価
- 既存: `feature_shared` の `EntityPickerDestination` は `PageDestination<String?>` で、id だけを返していた。表示名は呼び出し元が選択肢を読み直して引いていた。
- 抽象化した拡張プロジェクトは無かったため、`packages/core/selection_result` を新規に作成した。

## 実施
- `Selection`(Value Object): `entityKey`・`id`・`label`・`values`。`toJson`/`fromJson`(エラー追跡用)と、データ効率のよい `encode`/`decode`(短いキーの JSON)。
- `EntityPickerDestination` は `PageDestination<Selection?>` に変更(`feature_shared` が `selection_result` を再公開する)。編集画面の選択ボタンは `Selection.id` を使う(画面の挙動は同じ)。
- テスト 5 件。
