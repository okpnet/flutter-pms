# サーバーを使うテストが、JWT なし(匿名)で実行されるため、権限エラーになる

## 指示元
`flutter-pms/issue/20261111_0002.md`(受注・発注まわりの仕様変更に伴う先構築)の実行中に確認。2026-11-11。

## 症状
`serverTest` を使うテストが、`permission denied for schema tests` で失敗する。
- 例: `production_plan` の `graphql_mrp_gateway_test.dart`(`allTransMrpSuggestions`、`allSharedLanguageCodes`)。
- 原因: `TestServer` は `Authorization` を付けずに PostGraphile へ要求する。再構築後の PostgreSQL では、匿名のロール(`pms_anonymous`)にスキーマ `tests` の USAGE が無い(`has_schema_privilege = false`)。
- `CLAUDE.md`(認証)のとおり、JWT なしは `PermissionDeniedError` が正しい動き。テストの側が、現在の認証の仕組みに追従していない。

## 提案(判断が必要)
1. `TestServer` が、テスト用のユーザーの JWT を取得して `Authorization: Bearer` を付ける。
   - 取得は PocketBase(`POST /api/collections/users/auth-with-password` → `GET /api/app/graphql-token`)。
   - 資格情報は `--dart-define`(`PMS_TEST_POCKETBASE_URL`・`PMS_TEST_USER`・`PMS_TEST_PASSWORD`)か環境変数で渡し、ソース・Git に入れない。
   - 読み取りのテストは一般ユーザー(`pms_user`)、登録のテストも一般ユーザーで行う(`issue/20261111_0002.md` の 0-3「管理者だけで確認しない」)。
1. 取得できないとき(資格情報なし)は、`server` タグのテストを skip にする(今は接続できないときだけ skip)。
1. `FaultyGraphqlServer`(代役)を使うテストは影響なし。
