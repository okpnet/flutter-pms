# 20261028_0001 通信の異常を再現する代役サーバーの追加

- `FaultyGraphqlServer`(`lib/src/faulty_graphql_server.dart`)を追加: ローカルの`HttpServer`で、遅延・応答の途中の切断・応答前の切断・HTTPエラー(401/403など)を再現し、受け取った要求(認証ヘッダーを含む)を記録する。ポートは自動。
- `endedInTimeout`(`lib/src/timeout_outcome.dart`)を追加: `GraphQLClientProvider.query`の制限時間超過は、`GraphqlTimeoutException`と`Err(TimeoutError)`の両方で現れる(通信層のタイムアウトが同時に起きるため)。どちらも「タイムアウト」として扱う。
- `test/faulty_graphql_server_test.dart`(10件)を追加。全テスト17件が成功。
- 発見したライブラリ側の問題は`pms_graphql/issue/20261028_0001.md`に記載し、うち2件は修正した。
