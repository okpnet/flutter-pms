# 20261027_0007_add_1 各featuresの単体テストの差し替え

指示: [20261027_0007](20261027_0007.md)の「未対応・要判断」のうち、各`features`の単体テストの差し替え。

## 対象の調べ方
`packages/features/*/test`のうち、`IDataRepository`の代役、または`GraphqlDataRepository`を単体テストの代役にしているものを調べた。

| 機能 | 結果 |
|---|---|
| `dashboard_container` | 手書きの`_CountRepository`を`RecordingDataRepository<int>(result: 42)`に置き換え。記録は`lastTake`/`lastPredicate`から`calls`へ |
| `organization` | `staff_count_metric_source_test`が、検証の対象外の`GraphqlDataRepository`(と`fetch`関数)を代役にしていたため、`RecordingDataRepository`の`onFind`に置き換え。ページ送りの`skip`/`take`を`calls`で検証(GraphQLの変数名`offset`/`first`に依存しなくなった) |
| `shared_master` | 対象外。`IDataRepository`ではなく、この機能独自の`IShippingKindRepository`(保存・削除を含む)を使っており、メモリ上の実装は機能の標準の代役 |
| 上記以外(`app_core`・`item`など13機能) | 取得元を使うテストが無い(エンティティ・画面の確認のみ) |

## 変更
- `dashboard_container`・`organization`の`pubspec.yaml`の`dev_dependencies`に`data_test_harness`を追加。

## 確認
- `dashboard_container` 11件、`organization` 6件が成功。`data_test_harness`の検査テスト(dev依存のみ)を含む6件が成功。
