# 20261107_0001 AuthSession に役割(role)を追加

指示: [issue/20261107_0001.md](../../issue/20261107_0001.md)(指示したプロジェクト: `apps/pms_app`)

## 実施
- `AuthSession.role`(既定 `user`。PocketBase の `users.role`)と `isAdmin` を追加した。`fromAuthStore` が認証の記録の `role` を読む。`toJson` にも `role` を含める(トークンは含めない)。
- 既存の構築(`role` を渡さない)は `user` になり、互換。

## テスト
`pbapi` 56件通過(15件はサーバー接続が必要なためスキップ)。
