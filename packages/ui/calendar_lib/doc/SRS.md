## 1. はじめに

### 1.1 目的

calendar_lib: 月のカレンダー表示。日付ごとの値を抽象化した窓口で読み書きし、1 日・範囲の選択、開始曜日・表示する曜日・休日の色をテーマと設定で変えられる。

月のカレンダー表示のライブラリ(`packages/ui`。機能・DB を知らない)。稼働カレンダー(`resource`)などが使う。

### 1.2 範囲

- 場所: `packages/ui/calendar_lib`(ui(UI 基盤))
- 種類: Flutter パッケージ

## 3. 機能要件

このライブラリは、次の公開面(型・関数)を提供する。

| ID | 名前 | 種類 | 要求(ドキュメントコメントより) |
|---|---|---|---|
| FR-01 | `DateRange` | クラス | 日付だけ(時刻なし)の範囲。[start]・[end] を含む(両端を含む閉区間)。 |
| FR-02 | `CalendarDay` | クラス | カレンダーの 1 日。値 [value] は、取得元が決める型(稼働カレンダーなら、休日か・始業・稼働時間)。 |
| FR-03 | `ICalendarSource` | インターフェイス | カレンダーの取得元の窓口(Repository / Strategy)。画面は、保存先(GraphQL・メモリ)を知らない。 |
| FR-04 | `InMemoryCalendarSource` | クラス | メモリ上の取得元(テスト・example 用)。 |
| FR-05 | `CalendarTheme` | クラス | カレンダーの色・大きさ。テーマの拡張([ThemeExtension])として登録できる。 |
| FR-06 | `CalendarLabels` | クラス | カレンダーの文字(多言語)。既定は日本語。 |
| FR-07 | `CalendarController` | クラス | カレンダーの操作(選択・再読み込み・月の移動)。画面の外から使う。 |
| FR-08 | `CalendarCellBuilder` | 型の別名 | 日のセルに、日付の下へ出す中身を作る(null は何も出さない)。 |
| FR-09 | `CalendarView` | クラス | 月のカレンダー(月のグリッド)。 |
| FR-10 | `japaneseHolidays` | 関数 | 日本の国民の祝日(2000〜2099 年。振替休日・国民の休日を含む)。日付(時刻なし)→ 名前。 |
| FR-11 | `japaneseHolidayName` | 関数 | 日付 [day] が祝日なら、その名前。祝日でなければ null。 |

### 3.1 仕様の要点(`CLAUDE.md` より)

- **概要**: **データの抽象化**: 日付ごとの値(`CalendarDay<T>`)を、取得元の窓口 `ICalendarSource<T>`(`load`・`save`・`clear`)で読み書きする(Repository / Strategy)。保存先(GraphQL・メモリ)は画面が知らない。範囲の保存は日ごとの保存で、1 つのトランザクションにしない。失敗した…
