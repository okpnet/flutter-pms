# 20261105_0001 既定のテーマを画面案のデザインに合わせた

指示: `packages/features/issue/20261105_0001.md`。調査・実装の全体は `packages/features/doc/log/20261105_0001.md`。

## 変更
- 組み込みの既定(`default`)を、画面案(`tools/open-design`)のデザイントークンと同じ値にした(`openDesignTheme`)。ライト・ダークは独立の配色。
- 色の個別上書きに `background`・`primaryContainer`・`onPrimaryContainer`・`errorContainer`・`onErrorContainer`・`surfaceContainerHighest`・`onSurfaceVariant`・`outlineVariant` を追加。`ThemeMetrics.cardRadius`(任意)を追加。
- `ThemeBuilder` に、画面の地・カード(影なし+罫線)・タイトルバー・ダイアログ・シート・チップ・ナビゲーション・アウトラインボタン・区切り線・日本語優先のフォント代替を追加(すべてのテーマ共通)。
- 仕様は `CLAUDE.md` の「既定のテーマ(画面案のデザイン)」、JSON の項目表は `doc/contents/usage.md`。

## 互換性
- 既定のテーマの見た目が変わる(インディゴ → ティール、角丸 3 → 8/12、ボタンの最小 128x46 → 44x44、カードは影から罫線)。`ocean`・`forest` は配色・角丸は従来どおりで、カード・タイトルバーの面の区切りだけが罫線になる。
- 既存の JSON テーマは、そのまま取り込める(追加した項目はすべて任意)。
