# 20261020_0002 環境変更後のエラー解消と使用方法の再生成

## 1. 発生していたエラー

`dart analyze` で 10 件。すべて `lib/build/built_in_themes.dart` / `lib/build/theme_builder.dart` が存在しないことが原因。

- 原因: ルート `.gitignore` の `build/` が `lib/build/` にも該当し、この2ファイルが一度もコミットされていなかった。環境が変わった(新しい作業ツリー)ため消失した。
- 対応: ディレクトリ名を `lib/builder/` に変更して `ThemeBuilder` と `builtInThemes` を再作成。`theme_manager.dart` / `theme_lib.dart` の import / export を更新。
  - 復元の根拠: 既存テスト(組み込み `default`/`ocean`/`forest`、forest は radius 12・spacing 6、ボタン 128x46、線幅 0.8)、`SpaceField`/`BorderField`、`ThemeMetrics`、`doc/log/20261020_0001.md`、example。
  - 組み込みテーマの seed 色は元の値が失われているため新規に選定(default `#3F51B5` / ocean `#00838F` / forest `#2E7D32`)。**元の色と異なる可能性がある。**
  - `dark` 省略時は `light` の seed のみからダーク配色を生成する(light の個別指定色はダークで破綻するため重ねない)。

## 2. 環境の問題(コード外)

Flutter SDK が日本語を含むパス(`F:\data\ダウンロード\flutter`)にあり、`flutter test` のシェーダーコンパイルが文字化けで失敗する(`ShaderCompilerException`)。
- 回避: ジャンクション `C:\flutterSDK\flutter` → 上記 SDK を作成し、セッション中は `C:\flutterSDK\flutter\bin` を PATH の先頭にして実行した。
- 恒久対応にはユーザー環境の PATH を `C:\flutterSDK\flutter\bin` に変更するか、SDK を ASCII パスへ移す必要がある(未実施)。
- `screenshots_test.dart` が参照する `C:/flutterSDK/flutter/...` とも一致する。

## 3. 使用方法(doc/contents/usage.md)

`example/tool/screenshots_test.dart` で 6 枚のスクリーンショットを再生成し `doc/contents/images/` を更新した。`usage.md` 本文の変更は不要(参照パス・ファイル名は同一)。
