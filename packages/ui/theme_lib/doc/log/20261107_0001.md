# 20261107_0001 淡い赤系のテーマ(rose)の追加

指示: [issue/20261107_0001.md](../../issue/20261107_0001.md)(指示したプロジェクト: `apps/pms_app`)

## 実施
- `themes/rose.json` を追加(id `rose`、名前 `Rose`)。ライト・ダークの両方を個別に調整し、既定のテーマと同じ項目をすべて指定している。
  - ライト: 主色 `#A8324A`(くすんだ赤)、地 `#FBF3F4`、主色の薄い面 `#F8DDE1`。エラー色は既定と同じ赤で、主色と区別する。
  - ダーク: 主色 `#F2A3B1`、地 `#1A1013`。
  - 数値は既定と同じ(角丸 8/12、タップ領域 44)。
- `ThemeAssets.rose` を追加し、`ThemeAssets.all`(`ocean`・`forest`・`rose`)に含めた。`pubspec.yaml` のアセットにも追加。
- アプリが起動時に `ThemeAssets.all` を取り込むため、アプリの設定ページのテーマ選択に自動で並ぶ。

## テスト
`test/external_themes_test.dart` の対象に `rose` を追加(取り込み・全項目の指定・文字は 4.5:1 以上・枠は背景に対して 3:1 以上(ライト・ダーク)・登録)。61件通過。
見た目の確認(スクリーンショット)は、画面を立ち上げられる環境で行う。

## 課題
- 主色と同じ系統の淡い赤はエラー色(赤)と近く見える場合がある。エラーは文字・アイコンも併用しているが、見た目の確認後に調整する。
