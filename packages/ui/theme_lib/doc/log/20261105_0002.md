# 20261105_0002 追加のテーマの外部ファイル化と AppColors

指示: `packages/features/issue/20261105_0002.md`。全体は `packages/features/doc/log/20261105_0002.md`。

## 変更
- `AppColors`(`ThemeExtension`)を追加。`ColorScheme` から作り、focus だけ個別指定(色の個別上書きに `focus` を追加)。`focusColor` を設定。
- 文字の大きさ(28/20/16/14/12・太さ・行高)を全テーマに適用。
- フォント: OS のフォントだけ(Hiragino Sans → Yu Gothic UI → Meiryo)。Noto Sans JP を外し、同梱しない。
- `ocean`・`forest` を組み込みから外し、外部のJSONファイル(`themes/`)にした。既定と同じ全項目を指定。`ThemeManager.importAssets`・`ThemeAssets`・`importBundledThemes` で取り込む。
- 仕様: `CLAUDE.md` の「既定のテーマ」「追加のテーマ(外部のJSONファイル)」、`doc/contents/usage.md`。

## 互換性
- 組み込みは `default` の1つだけ。`ocean`・`forest` は取り込むまで選べない。

59 件成功(新規 `test/external_themes_test.dart`)。
