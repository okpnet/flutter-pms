# 20261022_0004 フィルタ複数条件・セル配置・ローディング位置・件数表示・英語ラベル

## 実施
- フィルタ: 1つの列に複数条件を指定できるようにした(ダイアログに「条件を追加/削除」)。見出しのフィルタアイコンの右に、その列の条件数を同じ大きさ(14)で表示
- セル: `ColumnDefinition.textAlign`/`overflow` を追加。未指定の `textAlign` は型で決定(数値=右、文字列=左、日付/時間=センター)。`overflow` は `TextOverflow`(標準 ellipsis)
- ローディング: header/footer のメッセージ+サークルの左右位置 `loadingAlignment`(左(標準)/中央/右)
- 件数表示: `countItems`(null=非表示)、`countPosition`(header(標準)/footer/none)、`countAlignment`(右(標準))、`countDirection`(横(標準)/縦)、`countHorizontalOrder`/`countVerticalOrder`。全N件・フィルタ適用N件・読込N件。文言は `TableLabels` の `{n}` 書式
- 多言語: `TableLabels.english` を追加(動作確認用)
- CLAUDE.md を更新(5 フィルタ、9-3-4 セル内の文字、15 多言語、19 ローディング、21 件数表示)。`doc/contents/usage.md` を更新
- example: 日本語/英語の切替ボタン(`LabelScope`)、「セル配置・件数表示」タブ(件数の場所/位置/並べ方/順、ローディング位置、各型の配置と overflow)を追加。既存タブも切替に追随

## 解釈・判断した点
- 条件数のバッジは「その列の条件数」(1件でも表示)
- 「読込N件」は、ページネーションなら今のページの行数、無限スクロールならこれまでに読み込んだ行数、一括読み込みならフィルタ後の行数
- 「全N件」は、ローダー使用(ページネーション/無限スクロール)はローダーの `totalCount`、それ以外は `items`(読み込んだ行)の件数
- 件数表示の「順」は、項目の選択(`countItems`)と並び順(`countHorizontalOrder`/`countVerticalOrder`)を分けて指定する。標準は 全→フィルタ適用→読込
- フィルタのダイアログのキーを `filterOperator`/`filterValue1` から `filterOperator.<行番号>`/`filterValue1.<行番号>` に変更(複数条件のため)
- 英語ラベルは動作確認用の同梱で、他言語は従来どおりアプリが `TableLabels` を渡す
