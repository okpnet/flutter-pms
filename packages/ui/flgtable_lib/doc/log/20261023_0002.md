# 20261023_0002 ツリーの件数表示・列のフィルタ有効/無効

## 実施
- **ツリーに件数表示(CLAUDE.md 21)を適用**: `TreeTable` は共通部分の件数表示(場所・左右・縦横・並び順・`TableLabels`)をそのまま使うが、項目の数え方が通常のテーブル向けのままだった(全=メモリ上のノード数、フィルタ適用/読込=表示中の行数)。ツリー向けに次のとおり直した
  - 全N件: ローダーが返した全件数(`totalCount`)。削除・取り消しで増減する
  - フィルタ適用N件: フィルタ有効時は階層に関係なく合致した件数(`filteredCount`)。無効時は全N件と同じ
  - 読込N件: 木に読み込み済みの行数(トップと、展開で読み込んだ子。縮小中の子も含む)
- **列のフィルタの有効/無効**: 実装(`ColumnDefinition.filterable`/`sortable`、標準true)は既にあったが、仕様に無かったため CLAUDE.md の「9. 列」に追加した(テーブルの有効と列の有効が両方真のとき使える。無効な列はポップアップを開かず、ソートせず、モバイルの検索/並び替えバーにも出さない)。テストが無かったので追加した
- CLAUDE.md の 21 に、ツリーでの項目の意味(7)を追加。`doc/contents/usage.md` を更新
- example: ツリーの件数表示を 全/フィルタ適用/読込 の3項目にした(以前は読込のみ)

## 確認
- `flutter analyze`(本体・example)問題なし
- `flutter test` 本体 105 件、example 32 件成功
- 実機の目視確認(`flutter run -d windows`)は未実施。ウィジェットテストで動作のみ確認

## 補足
- 「フィルタの有効/無効」は、新しい設定は増やさず既存の `filterable` を仕様に明記した(ソートの `sortable` も同様に明記)
- 長押しの離しはタップとしても扱われる(ヘッダにフィルタ不可・ソート可の列を長押しするとソートされる)。長押し用のハンドラが無い列では従来どおりの動き
