- **U 取り消し/やり直し**: `undo_redo`を組み込み。対象はセル編集・削除・フラグ・上下移動/ドロップによる並び替え・ツリーの親変更。`onUndone`/`onRedone`でアプリへ通知、`FlgTableController`に`undo/redo/canUndo/canRedo`、Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z。`undoStack`(共有)・`undoEnabled`・`undoLimit`(標準100)を追加。再読み込みでテーブルが持つ履歴を消す(渡された履歴は消さない)。
  - `undo_redo`側: `UndoStack({limit})`を追加(上限超過で古い履歴を捨てる)。テストを1件追加。

### ツリー(`tree_table_lib.dart`)
- `TreeTable<T>`(`treeLoader`、`rowKey`必須、`TreeConfig`、`cycleChecker`)。`tree_table_lib.dart`は通常のテーブルの入口(`flgtable_lib.dart`)も再エクスポートするので、1行で両方使える。
- インデント(1文字=1インデント、標準2、1以上)、関係線(表示/非表示、線種、太さ。色と太さの標準はテーマ)、アイコン(▶▼▷、読み込み中はサークル)。
- 子の読み込み: 展開時のみ、最大行数(`pageSize`)まで、続きは`もっと読み込む`(同じレベル・同じインデント)、`サークル+読み込み中`の行、再読み込みで全て縮小。子の数の列(`childCountColumnKey`、null は内部の列で標準1)。
- フィルタ: 階層に関係なく合致した行を全てトップノードにする(ローダーに`flatten`で依頼)。
- ドラッグドロップ: 行の右側=ドロップ先の子、左端付近=ドロップ先と同じレベル(親がなければトップ)。ドラッグオーバーは背景色。循環の防止は、通常の木は画面の親の連鎖、フィルタ有効時は`TreeCycleChecker`(なければドラッグ不可)、判定の失敗は拒否、展開時の循環データは追加しない。
- イベント: `onBeforeParentChange`(キャンセル可)/`onAfterParentChange`(動かす行`item`も渡す)。
- `StaticTreeSource`: メモリ上のデータ向けの読み込みと循環判定。

## 実装時に判断した点(指示の範囲内の解釈)
- 「左端付近」は、ドロップ先の行の左端から`(その行のレベル+1)×1レベルのインデント幅`以内とした。
- 取り消しの`onUndone`/`onRedone`のイベントに、親の変更用の`parent`を追加した(適用後の親)。
- ツリーのフラグは`_flagged`に保持するが、並びは変えない。
- フィルタ有効時の移動は、行を動かさず移動先の子の数だけ更新する(移動先が読み込み済みなら子としても表示)。取り消しはそれを元に戻す。
- テーブル間のドロップ(別のテーブルへ移動)は取り消しの対象外にした(相手のテーブルの状態を戻せないため)。
- 共有した履歴(`undoStack`を渡した場合)は、再読み込みで消さない。渡した側(アプリ)が管理する。
- 右クリックのメニューを選んだ後、キー操作(Ctrl+Z)が効くようテーブルにフォーカスを戻す。
