# 20261027_0002 列のプロパティ: 読み取り専用

指示: `issue/20261027_0002.md`(`packages/features/issue/20261027_0005.md` の対応)。

## 実施
- `ColumnDefinition` に `readOnly`(既定 false)と `editable` を追加した。
- `FlgTable`(`table_core.dart`)のセル編集の開始・確定・Enter キーの判定を、`setter` の有無から `editable` に変えた。読み取り専用の列は編集を始めない。
- `toJson` に `readOnly` を足した。使い方を `doc/contents/usage.md` に追記した。
- 利用側: `entity_screens` の台帳が、読み取り専用の項目(`FieldDefinition.readOnly`)を読み取り専用の列にする。

## 確認
- `flutter analyze` 問題なし。`flutter test` 115件成功(読み取り専用の列のテストを追加: `setter` があっても再タップ・Enter で編集を始めない)。
