# ログイン(Keycloak)

pms_app の `issue/20261026_0003.md` の指示。

1. ログインは Keycloak を使う。`legacy/pms_authenticator` を `packages/features/pms_authenticator` へ移動する(実行済み)。
    1. workspace に加える(`resolution: workspace`、依存は melos の bootstrap に合わせる)。
    1. ロガーは `pms_logger` から `logger_provider` の `ILoggerProvider` へ置き換える。
1. 移動後に行うこと(未実施): ログイン画面を機能として提供し(`app_core` のログイン、または `pms_authenticator` 側のページ)、アプリの `LoginRouter` を置き換える。
