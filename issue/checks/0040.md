## 基準
異常の台帳に、題名・内容・日付・報告者と、種類(複数あるときは ' / ' でつながる)・外部の異常(チェック)・クレームが出る。新規・保存・削除は出ない(読み取り専用)。利害関係者の列に名称(複数あるときは「名称 (件数)」)、対象の列に対象のシンボル(複数は ' / ' 区切り)が出る

## 履歴
- 移行前の記録(元の状態: 対応済(備考を台帳の列から外した。発見日。外部か内部かは種類から DB のビューが決める)): ①列の内容が違う。列が発生年月日=>発見年月日ではない、件名、詳細、報告者、備考=>詳細があるので不要、種類、外部の異常=>外部か内部の切り分けがAPP固有になるという話ではなかったか調査
